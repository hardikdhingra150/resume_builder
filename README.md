**Transform raw experience into ATS-optimized bullet points with AI. Build professional resumes in under 5 minutes with 2 stunning templates.**

## ✨ **Live Demo**
https://resume-builder-nu-blush.vercel.app

## 🎯 **Features**
- **🤖 AI Enhancement** - Gemini Pro converts raw text → ATS bullet points
- **📄 2 Templates** - Classic + Modern layouts
- **⚡ Lightning Fast** - Blank → PDF in < 5 minutes
- **💾 Auto-save** - Supabase PostgreSQL backend
- **📥 PDF Export** - Styled templates
- **🔐 Google OAuth** - One-click login
- **📱 Responsive** - Mobile + desktop

## 🛠 **Tech Stack**
React 18 + Vite + TailwindCSS + Supabase + Gemini AI + Vercel

## 🚀 **Quick Start**

git clone https://github.com/yourusername/ai-resume-builder.git

cd ai-resume-builder

npm install

npm run dev

## .env:

VITE_SUPABASE_URL=https://your-project.supabase.co

VITE_SUPABASE_ANON_KEY=your-anon-key

VITE_GEMINI_API_KEY=your-gemini-key

## ☁️ Deploy

vercel --prod
